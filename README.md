# Disease Prediction Using Machine Learning

## Project Overview
This project uses machine learning classification models
to classify the Breast Cancer Wisconsin dataset.

## Dataset
- Dataset: Breast Cancer Wisconsin Dataset
- Total records: 569
- Total features: 30
- Training records: 455
- Testing records: 114

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Algorithms
1. Logistic Regression
2. Random Forest Classifier

## Results

| Model | Accuracy |
|---|---:|
| Logistic Regression | 98.25% |
| Random Forest | 95.61% |

## Output Files
- model_accuracy.png
- logistic_regression_confusion_matrix.png
- random_forest_confusion_matrix.png
- model_comparison.csv
- results_summary.csv
- results_summary.txt

## How to Run
Install the required libraries and execute:

python main.py
